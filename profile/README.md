## Terrateam is now Stategraph Orchestration

Terrateam is now [Stategraph Orchestration](https://stategraph.com/product/orchestration). It is the same product under a new name. The source moved to [stategraph/stategraph](https://github.com/stategraph/stategraph), and the documentation is at [stategraph.com/docs](https://stategraph.com/docs/orchestration).

Stategraph Orchestration runs Terraform, OpenTofu, Terragrunt, CDKTF, Pulumi, or a custom command from pull requests on GitHub and GitLab. Plans and applies run on your own GitHub Actions or GitLab CI runners. It runs OPA and Conftest policies and Checkov scans on each plan, enforces approvals, detects drift, and records every run in an audit trail.

Repositories set up for Terrateam keep working. The GitHub Action stays at [terrateamio/action](https://github.com/terrateamio/action).
